# Discord 대화 기반 밈 답장 기능 의도

사용자가 `/밈`을 실행하면 봇이 현재 채널의 직전 대화 흐름을 읽고, 그 상황에 어울리는 밈 이미지나 GIF 한 개를 공개 답장으로 보낸다.

## 명령과 대화 범위

| 명령 | 동작 |
| --- | --- |
| `/밈` | 명령을 실행하기 직전의 대화를 바탕으로 밈 한 개를 골라, 참고한 사람 메시지 중 가장 최근 메시지에 답장한다. |

- 봇이 설치된 서버의 텍스트 채널과 스레드에서 사용한다. 포럼 포스트에서는 해당 포스트 안의 대화가 기준이다.
- 명령 직전부터 현재 채널이나 스레드의 기록을 거슬러 올라간다. 봇과 웹훅 메시지를 건너뛰고 텍스트나 지원 형식의 사진이 있는 사람 메시지를 최대 10개 모아 대화 순서대로 참고한다.
- 앞선 메시지로 대화의 상황과 말투를 파악하고, 마지막 메시지에 대한 반응을 고른다. 축하, 공감, 놀람, 가벼운 웃음처럼 대화에 맞는 반응을 우선한다.

## 맥락 판단과 밈 선택

- 자주 쓰이는 밈을 후보 목록에 등록한다. 각 후보에는 이미지나 GIF와 함께 어떤 상황에 어울리는지 설명을 붙인다.
- 각 메시지는 `<닉네임>`과 본문으로 표시한다. 첨부 사진이나 본문에 들어간 서버 이모티콘은 `<사진1>`, `<이모티콘1>` 같은 표기를 붙이고, 같은 이름의 이미지 데이터를 같은 Gemini 요청에 담는다.
- Gemini는 시간순으로 정리한 대화, 이미지, 밈 후보 설명을 받아 마지막 메시지에 어울리는 밈의 ID나 `null`을 반환한다. 봇은 목록에 있는 ID를 확인한 뒤 해당 파일을 게시한다.
- 실행 로그에는 선택한 메시지 ID와 Gemini 요청에 쓴 대화 본문, 전송한 이미지의 표기, 읽지 못한 이미지의 표기를 남긴다. 실제 채팅을 Gemini에 연결할 때는 Discord의 데이터 제공 조건과 사용하는 Gemini 플랜의 데이터 처리 조건을 확인한다.

## 답장과 안내

- 성공하면 대화 참여자 모두가 볼 수 있도록 이미지나 GIF 한 개를 표시한다. 답장 알림과 사용자 멘션은 끈다.
- 참고할 대화가 없거나 문맥이 부족하거나 어울리는 밈이 없으면 명령 실행자에게만 `최근 대화에 어울리는 밈을 찾지 못했어요.`라고 안내한다.
- 기록을 읽을 권한이 없거나 맥락 판단 또는 게시에 실패하면, 가능한 경우 명령 실행자에게만 원인에 맞는 짧은 안내를 보여준다.

## 사용 예시

A가 `드디어 이번 과제 끝냈다`라고 말하고 B가 `이제 좀 쉬자`라고 답한다. 이어서 `/밈`을 실행하면, 봇은 가볍게 축하하는 의미로 잔을 들어 건배하는 이미지 한 장을 B의 메시지에 답장한다.
