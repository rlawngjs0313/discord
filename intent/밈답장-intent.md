# Discord 대화 기반 밈 전송 기능 의도

사용자가 `/밈`을 실행하면 봇이 현재 채널의 직전 대화 흐름을 읽고, 그 상황에 어울리는 밈 이미지나 GIF 한 개를 같은 채널에 공개 일반 메시지로 보낸다.

## 명령과 대화 범위

| 명령 | 동작 |
| --- | --- |
| `/밈` | 명령을 실행하기 직전의 대화를 바탕으로 밈 한 개를 골라 현재 채널이나 스레드에 보낸다. |

- 봇이 설치된 서버의 텍스트 채널과 스레드에서 사용한다. 포럼 포스트에서는 해당 포스트 안의 대화가 기준이다.
- 명령 직전부터 현재 채널이나 스레드의 기록을 거슬러 올라간다. 봇과 웹훅 메시지, 대화 끝에 이어진 링크만 있는 메시지를 건너뛰고 텍스트나 지원 형식의 사진이 있는 사람 메시지를 최대 10개 모아 대화 순서대로 참고한다.
- 테스트용으로 최신 사람 메시지에 `닉네임 — 어제 17:11` 머리글이 붙은 대화를 통째로 붙여넣으면, 그 블록의 마지막 10개 발언을 화자별로 읽는다.
- 앞선 메시지를 주제와 상황별로 나눠 마지막 발언이 속한 흐름을 고른다. 다른 주제가 중간에 끼어 있으면 마지막 발언과 이어지는 발언만 고른다. 그 흐름의 중심 사건, 소재, 행동과 연결되는 짤·사진·게임 장면을 사용한다. 감정과 말투는 비슷하게 어울리는 후보를 비교할 때 참고한다.

## 맥락 판단과 밈 선택

- 각 메시지는 `<닉네임>`과 본문으로 표시한다. 첨부 사진이나 본문에 들어간 서버 이모티콘은 `<사진1>`, `<이모티콘1>` 같은 표기를 붙이고, 같은 이름의 이미지 데이터를 같은 Gemini 요청에 담는다.
- Gemini는 마지막 흐름의 발언 번호, 주제, 밈 소재와 검색어를 반환한다. 봇은 Brave에 검색어만 전달해 검색당 최대 5개 후보를 찾는다. Gemini는 같은 발언, 연결된 이미지, 후보 제목과 썸네일을 보고 결과 ID나 `null`을 반환한다. 첫 검색에서 어울리는 후보나 접근 가능한 원본을 찾지 못하면 같은 주제로 국내 커뮤니티식 짤을 한 번 더 검색한다.
- 실행 로그에는 조회한 메시지 ID와 번호가 붙은 대화 본문, 이미지 표기, 검색에 사용한 발언 번호, 검색어와 선택한 결과 ID를 남긴다. 실제 채팅을 Gemini에 연결할 때는 Discord의 데이터 제공 조건과 사용하는 Gemini 플랜의 데이터 처리 조건을 확인한다.

## 전송과 안내

- 성공하면 대화 참여자가 볼 수 있는 일반 메시지에 이미지나 GIF 한 개를 첨부한다. 메시지 알림과 사용자 멘션은 끈다.
- `MEME_DISCORD_SEARCH_PREVIEW=true`이면 후보 선택 후 해당 검색의 후보 최대 5개와 선택 번호를 실행자에게만 보여주고 완료한다.
- 참고할 대화가 없거나 문맥이 부족하거나 어울리는 밈이 없으면 명령 실행자에게만 `최근 대화에 어울리는 밈을 찾지 못했어요.`라고 안내한다.
- 기록을 읽을 권한이 없거나 맥락 판단 또는 게시에 실패하면, 가능한 경우 명령 실행자에게만 원인에 맞는 짧은 안내를 보여준다.

## 사용 예시

A가 `드디어 이번 과제 끝냈다`라고 말하고 B가 `이제 좀 쉬자`라고 답한다. 이어서 `/밈`을 실행하면, 봇은 가볍게 축하하는 의미로 잔을 들어 건배하는 이미지 한 장을 같은 채널에 보낸다.
